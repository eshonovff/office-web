## Definition of Done
- Се канал дар як рӯйхат бо иконкаи худашон
- 500 паёмро скролл мекунӣ — ларзиш нест
- Паёми нав ҳангоми скролли кӯҳна ҷои скроллро намепарронад
- Тағйири статус ва таъин дар браузери дигар фавран
- Ёддошти дохилӣ ба мижоз намеравад
- Тиреза баста → composer блок бо матни фаҳмо
- Линки `?conversationId=` дар браузери нав ҳамон чатро мекушояд
- Operator танҳо каналҳо ва чатҳои худро мебинад
