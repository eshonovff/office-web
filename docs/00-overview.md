# 00 — Тасвири умумӣ

## Барои кӣ

5–10 корманди SMARTWEB TJ. Ҳама паси login.

| Роль | Чӣ мебинад |
|---|---|
| Owner | ҳама |
| Admin | ҳама ғайр аз кормандон ва ролҳо |
| Developer | проект ва таск |
| Operator | танҳо инбокс |
| Manager | инбокс + таск |

Як нафар якчанд роль дошта метавонад. Frontend рольро намесанҷад —
`permissions[]`-ро месанҷад.

## Саҳифаҳо (7)

| Роут | Мазмун |
|---|---|
| `/login` | вуруд |
| `/` | dashboard — таскҳои ман, чатҳои ҷавобнадода |
| `/projects`, `/projects/:id` | рӯйхат ва Kanban |
| `/inbox`, `/inbox/board` | чат ва Kanban-и чатҳо |
| `/users` | кормандон, ролҳо, доступ |
| `/roles` | ролҳо ва permission-ҳо |
| `/settings` | шаблонҳо, профил |

## Ду саҳифаи ғайримуқаррарӣ

Ҳамаи саҳифаҳои дигар намунаи оддии «рӯйхат + форма»-и Nizom-ро
такрор мекунанд. Ин ду не:

**Kanban (`/projects/:id`)** — dnd-kit, optimistic move, оштӣ бо SignalR.
Ин ҷо `DataTable` кор намекунад.

**Инбокс (`/inbox`)** — рӯйхати чат бо cursor pagination дар чап,
муколама бо скролли баръакс дар рост, composer дар поён,
таймери тирезаи 24-соата. Ду view: чат ва Kanban.
